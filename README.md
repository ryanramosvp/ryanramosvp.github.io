# ryanramosvp.github.io

Portfólio pessoal, publicado em **https://ryanramosvp.github.io**

Página única, sem dependência de build: um `index.html` com o CSS e o
JavaScript embutidos. As únicas requisições externas são as fontes do Google
Fonts.

O fundo animado (faixas diagonais e poeira luminosa) é desenhado em canvas, e
toda a animação é desligada quando o visitante pede `prefers-reduced-motion`.

Para editar, abra `index.html` direto. Qualquer commit na branch `main` vai ao
ar em poucos minutos pelo GitHub Pages.
